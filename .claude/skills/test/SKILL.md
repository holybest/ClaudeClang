# 테스트

1. 먼저 `/build` 절차로 빌드한다. 빌드가 실패하면 테스트를 실행하지 않는다.
2. 테스트를 실행한다:
   ```sh
   ctest --test-dir build --output-on-failure
   ```
   인자로 테스트 이름 패턴이 주어지면 `-R <pattern>`을 붙인다.
3. 등록된 테스트가 없으면("No tests were found") 그렇게 보고하고, `test-writer` 서브에이전트로 테스트를 추가할지 제안한다.
4. 실패한 테스트마다 테스트 이름, 실패한 단언(assertion), 관련 소스 위치(`파일:줄`)를 정리한다. 테스트 결과를 통과로 꾸미거나 실패한 테스트를 건너뛰도록 고치지 않는다.
