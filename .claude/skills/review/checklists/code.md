# 코드 리뷰 체크리스트 (SWE.3 구현)

| ID | 점검 항목 |
|----|-----------|
| COD-01 | 모든 함수가 반환값을 가진다. `void` 함수가 없다(예외는 코드 주석에 사유가 있다). |
| COD-02 | 반환할 값이 없는 함수는 정상 실행 여부를 알 수 있는 상태 코드를 반환한다. |
| COD-03 | 모든 함수에서 `return`이 함수 마지막에 한 번만 있다. 중간 return·조기 반환이 없다. (함수 본문을 직접 읽어 확인) |
| COD-04 | 호출자가 반환 상태 코드를 검사한다. 무시하면 안 되는 반환값에 `[[nodiscard]]`(또는 동등한 장치)가 있다. |
| COD-05 | 소스가 상세 설계(`DD`)의 모듈·함수·인터페이스와 일치한다. 설계에 없는 공개 함수·타입이 없다. |
| COD-06 | 인터페이스가 있는 모듈은 인터페이스로만 접근된다. 내부 함수는 `static`/익명 네임스페이스이고 헤더에 내부 구현이 노출되지 않는다. |
| COD-07 | 단일 책임, 클린 코드: 함수가 짧고 한 가지 일을 하며 이름이 의도를 드러내고 중복·매직 넘버가 없다. |
| COD-08 | 메모리·자원 안전: 해제 후 사용, 이중 해제, 누수, 버퍼 오버런, 초기화되지 않은 변수, dangling 참조가 없다. 소유권이 스마트 포인터/RAII로 표현된다. raw `new`/`delete`가 없다. |
| COD-09 | 정의되지 않은 동작이 없다(부호 있는 정수 오버플로, strict aliasing, 수명 종료 객체 접근 등). |
| COD-10 | 입력 검증: 외부에서 들어오는 인자·데이터를 사용 전에 검증한다(null, 범위, 길이). |
| COD-11 | 동시성이 있는 경우 데이터 경쟁과 락 순서 문제가 없다. |
| COD-12 | 컴파일러 경고(`-Wall -Wextra -Wpedantic`)와 `clang-tidy`/`clang-format` 지적이 없다. 경고 억제(`-Wno-*`, `#pragma`)가 없거나 사유가 있다. |
| COD-13 | 모든 함수에 Doxygen 주석(`@brief`, `@param`, `@return`)과 구현하는 설계 ID(`@design DD-nnn`)가 있다. |
| COD-14 | `links.csv`에 `DD → SRC` 링크가 있고 `check_traceability.py --until code`가 통과한다. |
| COD-15 | 제한(`SWR-LIM`: 시간·메모리 등)과 제약(`SWR-CON`: 동적 할당 금지 등)을 위반하지 않는다. |
| COD-16 | 데드 코드, 주석 처리된 코드, 사용되지 않는 변수·함수가 없다. |
