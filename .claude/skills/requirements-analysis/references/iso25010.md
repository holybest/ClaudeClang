# ISO/IEC 25010 제품 품질 모델

품질 요구사항(`SWR-QUA`)의 `품질 특성` 필드에는 아래 특성/부특성 이름을 그대로 사용한다.

| 특성 | 부특성 | 측정 기준 예시 |
|------|--------|----------------|
| 기능 적합성 (Functional suitability) | 기능 완전성, 기능 정확성, 기능 적절성 | 요구 기능 구현율, 계산 오차 ≤ 0.1 % |
| 성능 효율성 (Performance efficiency) | 시간 반응성, 자원 활용성, 용량 | 최악 응답 시간 ≤ 10 ms, RAM ≤ 64 KB |
| 호환성 (Compatibility) | 공존성, 상호운용성 | 지정 프로토콜 버전과 메시지 교환 성공 |
| 사용성 (Interaction capability) | 적절성 인식도, 학습 용이성, 운용 용이성, 사용자 오류 방지, 사용자 인터페이스 심미성, 접근성 | 오류 입력 시 진단 메시지 제공 |
| 신뢰성 (Reliability) | 성숙성, 가용성, 결함 허용성, 회복성 | 가용률 ≥ 99.9 %, 장애 후 복구 ≤ 1 s |
| 보안성 (Security) | 기밀성, 무결성, 부인방지, 책임추적성, 진본성 | 입력 길이 검증, 서명 검증 실패 시 거부 |
| 유지보수성 (Maintainability) | 모듈성, 재사용성, 분석성, 수정성, 시험성 | 모듈 순환 복잡도 ≤ 10, 단위 시험 가능 |
| 이식성 (Portability) | 적응성, 설치성, 대체성 | 지정 플랫폼 2종에서 빌드·시험 통과 |

버전별로 일부 명칭이 다르다(예: 2023판은 "사용성"이 "상호작용 능력", "안전성(Safety)" 특성 추가).
프로젝트에서 사용하는 판을 CLAUDE.md에 한 번 명시하고 그 판의 명칭을 일관되게 쓴다.
ISO 25010의 안전성(Safety) 특성에 해당하는 요구사항은 `FSR`로 `docs/safety/`에서 관리한다.
